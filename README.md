# ConnectedSE 2027

Website of ConnectedSE 2027, the First International Workshop on LLM-Assisted Software Engineering at the Intersection of Mobile and Cyber-Physical Systems, co-located with FSE 2027.

## Publishing on GitHub Pages

1. Create the repository `2027` in the `ConnectedSE` GitHub organization.
2. Upload the contents of this folder to the root of the repository.
3. In Settings > Pages, select "Deploy from a branch", branch `main`, folder `/ (root)`.

The site will be available at https://connectedse.github.io/2027/.

## Editing

The whole site is in `index.html`.

- Remove the orange status banner (marked by a comment) once the workshop is accepted.
- Add confirmed program committee members in the commented block of the Organization section.
- To show organizer photos, put them in `img/` and replace each `<div class="avatar">XX</div>` with `<img class="avatar" src="img/name.jpg" alt="Name">`.
